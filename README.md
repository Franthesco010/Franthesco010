💻 Entendendo os Sistemas Operacionais
Para criar jogos eficientes, não basta apenas programar: é preciso entender a base de tudo. O Sistema Operacional (SO) é o software fundamental que gerencia o hardware do computador e permite que os aplicativos funcionem.

Gerenciamento de Recursos: O SO distribui a capacidade de processamento da CPU e gerencia a memória RAM para que o Godot, o VS Code e os jogos rodem ao mesmo tempo sem travar.

Ambientes de Desenvolvimento: Sistemas como o Windows e o Linux são os mais comuns para desenvolvedores. Conhecer como eles funcionam ajuda a otimizar melhor o desempenho dos jogos e a entender como o código interage diretamente com a máquina.
